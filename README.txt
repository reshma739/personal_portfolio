- style.css          Shared styles for every page

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Use the top navigation to move between separate pages.

EDIT LATER:
- In contact.html, replace the three "Add your..." lines with your real email,
  LinkedIn URL and GitHub URL. Add clickable links when you have the URLs.
- Update any project or education details whenever needed.
- The Google Fonts import requires an internet connection; fallback fonts are included.

TECHNOLOGY:
HTML5 and CSS3 only. No JavaScript, framework, backend or database.
The mobile navigation uses a CSS checkbox menu.
